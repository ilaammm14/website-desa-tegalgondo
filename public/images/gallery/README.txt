FOLDER UNTUK FOTO GALERI

Simpan foto galeri di folder ini mengikuti penamaan yang ada di data/gallery.ts.

Contoh nama file:
- desa-01.jpg
- desa-02.jpg
- desa-03.jpg
- masyarakat-01.jpg
- masyarakat-02.jpg
- pertanian-01.jpg
- pertanian-02.jpg
- kegiatan-01.jpg
- kegiatan-02.jpg
- budaya-01.jpg
- lingkungan-01.jpg
- lingkungan-02.jpg

CARA MENAMBAH FOTO BARU:
1. Simpan foto di folder ini
2. Buka data/gallery.ts
3. Tambahkan entry baru di array galleryItems
4. Set isPlaceholder: false

UKURAN FOTO YANG DISARANKAN:
- Format: JPG atau WebP
- Kualitas: 80-85%
- Ukuran max per foto: 500KB
- Dimensi: bebas (masonry layout akan menyesuaikan)

TIPS:
- Foto portrait (tinggi) cocok untuk variasi masonry
- Kompres foto sebelum upload menggunakan TinyPNG atau Squoosh
